# ADR-0002：评分透明可复算是第一原则

- 状态：已采纳（M0）
- 日期：2026-08

## 背景

排行类项目的生死线是信任。黑盒评分（「算法推荐」不说公式）会被质疑操纵；按 Stars 简单排序（WhaleHub 的做法）则被刷星污染且无质量信号。

## 决策

评分公式、权重、排除规则全部公开，并且**可复算**：任何人 clone 仓库跑 `node scripts/sync.mjs`，应得到与 `data/` 一致（或仅时间戳不同）的结果。权重变更必须走「改文档 + 改代码 + 全量重算 + PR 附新旧 Top20 对比」流程。

## 理由

1. 「跑一遍脚本给你看」是对任何质疑的终极回应
2. 约束我们自己：不能悄悄调参讨好任何一方
3. meta.json 携带公式快照，历史数据的可解释性随时间保留

## 代价

- 评分模型的每次演进都要付出文档与评审成本（刻意为之）
- 依赖数据源（GitHub API 字段）的语义变化需要显式跟进
